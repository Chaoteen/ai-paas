redis_bus.py = 消息总线 库 (可复用组件)

run_bus.py = 总线 服务 (具体应用)

redis_bus.py 是核心消息总线实现，所有消息都经过这里

run_bus.py 只是总线的一个使用示例/启动脚本

      ▼

      │
      ▼
agent.tasks.stream
      │
      ├──► PromptEngine Service → agent.prompt.*
      ├──► Agent Service        → agent.model.*

      ▼

      │
      ▼
gRPC Gateway (结果推送回Client)
